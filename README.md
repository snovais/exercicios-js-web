## 📖 Sobre o Projeto

Este repositório contém **5 exercícios práticos** desenvolvidos para ajudar iniciantes a aprender os fundamentos do JavaScript aplicado ao desenvolvimento web.

Cada exercício foca em um conceito diferente, desde manipulação básica do DOM até validação de formulários e criação de componentes interativos.

### 🎯 O que você vai aprender:

- ✅ Manipular o **DOM** com `getElementById`
- ✅ Trabalhar com **eventos** como `onclick`
- ✅ Criar **interatividade** sem recarregar a página
- ✅ Validar **formulários** com JavaScript
- ✅ Manipular **arrays e listas** dinamicamente
- ✅ Alterar **estilos CSS** via JavaScript

## 📚 Exercícios

| # | Exercício | Descrição | Conceitos |
|---|-----------|-----------|-----------|
| 1 | **Saudação Personalizada** | Campo de texto que exibe "Olá, [nome]" | `getElementById`, `value`, `innerHTML` |
| 2 | **Calculadora Simples** | Soma dois números e exibe o resultado | `Number()`, operadores matemáticos |
| 3 | **Mudar Cor do Quadrado** | Botões que alteram a cor de um quadrado | `style.backgroundColor`, eventos |
| 4 | **Lista de Tarefas** | Adicionar e remover tarefas da lista | `createElement`, `appendChild`, `remove()` |
| 5 | **Validação de Formulário** | Verifica email (@) e tamanho da senha | Condicionais, `indexOf`, `length` |
